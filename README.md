# Multimodal AI Safety Evaluation Lab

A practical portfolio project for evaluating AI safety and reliability
across text, image, and audio systems.

## Projects

### 1. Text Safety Evaluation
- Prompt injection resistance
- Instruction following
- Response quality checks

### 2. Image Safety Evaluation
- Image description accuracy
- Visual question answering
- Handling untrusted text in images

### 3. Audio Safety Evaluation
- Speech transcription accuracy
- Noise robustness
- Transcription error analysis

## Principles
- Use authorized, controlled test environments.
- Keep test inputs and evaluation criteria documented.
- Separate automated scores from manual review.
- Report limitations and avoid unsupported safety claims.

## Status
Initial project structure. Evaluation suites are under development.
